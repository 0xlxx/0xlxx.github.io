publishedAt: '2026-05-31'
summary: '关闭 Pi web_search 的交互式浏览器策展器（workflow: "none"），让搜索在后台静默完成。'
---

Pi 的 `web_search` 默认会弹出一个交互式浏览器策展器（curator），让你在浏览器里筛选结果、写摘要。大多数时候这个体验很好，但如果只想快速查点东西、不想被打断，这个弹窗就有点烦了。

## 一句话方案

传 `workflow: "none"` 即可：

```
web_search({
  query: "React 19 server components",
  workflow: "none"
})
```

这样搜索结果直接返回，不会打开浏览器。

## workflow 的两个值

| 值 | 行为 |
|---|---|
| `"summary-review"` | **默认**。打开浏览器策展器，可手动筛选结果、写摘要 |
| `"none"` | 静默模式。跳过策展器，结果直接返回到对话中 |

## 什么时候用 "none"

- 快速查一个 API 签名或报错信息
- 批量搜索（多个 query），不想每个都弹窗
- 在 terminal-only 环境里工作，没有浏览器
- 让 agent 自动搜索而不用等你手动操作

## 什么时候保留 "summary-review"

- 搜索结果多，需要人工筛选相关来源
- 需要对比多个来源的结论
- 写的摘要会被后续对话引用

## 实际例子

```typescript
// 快速查一个报错
web_search({
  query: "Next.js TypeError undefined is not a function middleware",
  workflow: "none"
})

// 批量研究，传 queries 数组
web_search({
  queries: [
    "Bun vs Node.js performance 2026",
    "Bun runtime production readiness",
    "Bun compatibility with Next.js"
  ],
  workflow: "none"
})
```

一个小参数，省掉不少切换窗口的时间。
